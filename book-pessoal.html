Trabalho pessoal

Book pessoal de moda

Um ensaio pessoal com olhar de fotógrafo de moda: 25 fotos para o seu portfólio, o seu perfil profissional, as suas redes e o seu uso pessoal.

Valor

R$ 1.500 pelo book pessoal de moda: sessão individual, 25 fotos. O valor é para uma pessoa.

O que é um book pessoal

Book pessoal (ou ensaio pessoal) é um trabalho feito para você, pessoa física. É o caminho para quem quer boas fotos de si mesmo, com a direção de quem fotografa moda: para um portfólio, um perfil profissional, as redes sociais ou simplesmente para ter as imagens.

O local e a data são combinados com você.

O que este valor não inclui

O valor acima vale somente para book pessoal e ensaio pessoal. Ele não se aplica a trabalhos de marca: lookbook, campanha, publicidade e fashion film são orçados por projeto, sem valor de tabela. Se você é uma marca, veja o Lookbook e a Campanha e peça um orçamento pelo Contato.

Perguntas frequentes

Quanto custa um book pessoal de moda?

R$ 1.500, para uma pessoa, com 25 fotos.

Esse valor serve para uma marca ou para um lookbook?

Não. O valor é só para book e ensaio pessoal. Trabalhos de marca (lookbook, campanha, publicidade, fashion film) são orçados por projeto.

E se forem mais pessoas?

O valor é para uma pessoa. Para mais de uma, conte pelo WhatsApp quantas são e peça uma proposta.

Para agendar o seu book pessoal, chame pelo WhatsApp e conte quando e onde você gostaria de fazer.
